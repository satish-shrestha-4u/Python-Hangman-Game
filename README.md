# Python Hangman Game

This is a simple command-line Hangman game built with Python.

The project was created as part of my Python learning practice to strengthen my understanding of loops, conditionals, functions, strings, lists, and user input.

## Files

- `hangman.py` — main Python script version of the game
- `hangman_with_hints.ipynb` — notebook version created during practice

## Features

- Letter-by-letter guessing
- Hidden word display
- Attempt tracking
- Win/loss condition
- Basic hints

## Tools Used

- Python
- Jupyter Notebook / Google Colab

## How to Run

```bash
python hangman.py
```

## What I Practised

- Python functions
- While loops
- Conditional statements
- Lists and strings
- User input
- Debugging
